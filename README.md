# Sistema de Profesores y Estudiantes

## Descripción

Este proyecto consiste en desarrollar un sistema en Java
que permite registrar profesores y sus respectivos estudiantes,
utilizando la estructura de datos ArrayList.

## Objetivo

Administrar la información de profesores y estudiantes,
permitiendo realizar diferentes consultas mediante un menú.

## Funcionalidades

1. Registrar profesores.
2. Registrar estudiantes asociados a cada profesor.
3. Consultar todos los profesores y sus estudiantes.
4. Consultar un profesor y sus estudiantes.
5. Consultar la cantidad de estudiantes por profesor.
6. Consultar el director de grupo de un estudiante.

## Requisitos implementados

- Uso de ArrayList.
- Uso de ArrayList anidados.
- Uso del método contains().
- Uso del método indexOf().
- Uso del método size().
- Menú interactivo.
- Validación de registros duplicados.
- Validación de consultas sin registros.
- Programación orientada a objetos.

## Herramientas utilizadas

- Java 17.
- IntelliJ IDEA.
- Git.
- GitHub.

## Estructura del proyecto

- Principal.java
- ProfesoresEstudiantes.java
- evidencias/

## Ejecución

Abrir el proyecto en IntelliJ IDEA,
ejecutar Principal.java y seleccionar las opciones del menú.
